**Decisions and assumptions**
- **ADM-1** Administrators change configuration; reads of configuration are administrator-only except the class tree, list pickers, a part's classification and the search.
- **ADM-2** Only parts store attribute values today; document and change attributes throw `NotSupportedException` (Phase 2c).
- **ADM-3** Lifecycles: version 1 id = family name, version n = `<family>~v<n>`; published versions immutable (DB triggers; migrator exempt); new objects use the current version; migration is explicit, mapped, audited.
- **ADM-4** Protected states and transitions that code refers to by name cannot be removed or retagged; PR/ECR/ECN/CT lifecycles are view-only (Phase 5).
- **ADM-5** Part and document types can bind a lifecycle family; the default family applies otherwise.
- **ADM-6** Reference lists are retired, never deleted; EA and Class I/II cannot be retired; change classes only relabel; change prefixes fixed.
- **ADM-7** Number counters only advance; a prefix or advance that hits an existing number is refused.
- **ADM-8** Template pins: used when the caller names no template; an explicit choice wins.
- **ADM-9** Programs and offices lists are UI pickers only; access still comes from IdP security attributes (A2).
- **ADM-10** One class per part; class and values are iteration-owned (working copy, frozen at check-in, copied on revise); a retired class cannot be newly frozen, an unchanged one can stay.
- **ADM-11** Class attribute names are unique along a path; depth at most 12; classes are never deleted.
- **ADM-12** Move, retire and attribute edits validate classified latest iterations and working copies; counts are exact, part numbers shown only for parts the admin may read.
- **ADM-13** Review signatures cover classification (`$owned` key) for classified parts only; existing hashes unchanged.
- **ADM-14** Config import applies item by item through the services (not atomic), idempotent, stops at the first error; items absent from the file are untouched; template/lifecycle/pin ordering is fixed.
- **ADM-15** Search facets use the attributes of the selected subtree and ignore their own filter; classification search ranges over latest iterations only.
- **ADM-16** Lifecycle usage counts and the migration run in SQL functions (`cfg.lifecycle_usage`, `cfg.migrate_lifecycle_objects`) that return/modify no marked columns.
