# UX-1: app shell, Home, command palette, redesigned object pages (increment 7.0)

Design: [ADR-0028](../adr/0028-ui-shell-and-workspace.md). Rules for new pages: [design-system.md](../ux/design-system.md).

## Delivered
- Design system with light, dark, high-contrast and system themes, density, tokens, SVG sprite; preference stored server side and rendered into `<html>` by the static shell.
- Shell: skip link, grouped rail (collapsible, drawer below 768 px), breadcrumbs, user menu (My access, theme, density, lock, sign out), search button, session hint and Lock now kept.
- Home dashboard (`/`): Needs my attention, Recently viewed, Favorites, Changes in my programs, Recently released, Quick actions; independent skeletons and failures; banner = aggregate of the shown rows.
- Command palette (Ctrl/Cmd+K, `/`) and `/search` (tabs per kind, saved searches), typed prefixes `p: d: c: ecn: ecr: pr: b: mb:`.
- Object pages (part, document, change, baseline, manufacturing BOM): header, stepper, sticky actions, tabs with deep links, favorite star, recently viewed tracking, `<title>` with number and name.
- Feedback: toasts, confirm dialog (undo check-out, set-state override), empty states, skeletons, unsaved-changes guard. Sortable `DataTable` on parts, documents, changes, baselines, MBOMs, tasks, audit.
- Jargon removed from user text (UiText maps reason codes, state "via" messages, admin pages); jargon scan test with allow-list.
- Migration `0014_workspace.sql` and module `Keel.Workspace`.

## Assumptions
- UX-1: Theme, density and rail state are per user, server side; the first response already carries them.
- UX-2: Tabs render only the selected panel; banners of hidden panels leave the page banner.
- UX-3: Table sorting is within the displayed page (services take no sort order); the header tooltip says so. Server sort keys are supported by `DataColumn` for later.
- UX-4: The palette sends nothing for under two characters; each search is audited by its module as any search is.
- UX-5: Recent items keep 50, favorites 100, saved searches 50, table layouts 200; repeat views within 60 s are not written.
- UX-6: Saved-search text is private to its owner; audit sees scope and SHA-256 only. Views and favorites are not audited.
- UX-7: Stored pointers are re-authorized on every render and dropped silently; no "no longer available" rows.
- UX-8: "Recently released" means state code `Released` of parts and documents changed in the last 30 days; decisions on the user's changes are shown for 14 days.
- UX-9: The sign-out form lives once in the layout (`#signout-form`); the user menu and the palette submit it.
- UX-10: A "Lock session now" item is in the user menu in addition to the header's Lock now button.
- UX-11: Heading levels inside older panels still start at h3 under the page h1; each tab panel adds a hidden h2 with the tab name.

## Not done / follow-ups
- Server-side sorting needs a sort parameter in each module search.
- Inline confirm panels of administration pages (publish, retire) were not converted to `ConfirmDialog`; cancel-review inputs of review panels were left as they are.
- Relationship pictures (UX-3), notification center (UX-4).
- Backup note: the `ws` tables are low-value personal data; they are in the normal database backup and need no special restore handling.
