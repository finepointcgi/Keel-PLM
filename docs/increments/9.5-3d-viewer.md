# 9.5 Assembly placements and the Viewer tab (2026-10-30)

ADR-0052, migration 0031, assumptions A67 to A69. Guides: [integration/cad-connector.md](../integration/cad-connector.md), manual chapters [5](../manual/05-documents-and-vault.md#the-viewer-tab-3d-models-on-the-page) and [11](../manual/11-cad-connector-and-freecad.md).

## Delivered
- **Placements from STEP.** `StepStructureReader` reads, in the same pass as the products, the chain `NEXT_ASSEMBLY_USAGE_OCCURRENCE`, `PRODUCT_DEFINITION_SHAPE`, `CONTEXT_DEPENDENT_SHAPE_REPRESENTATION`, `REPRESENTATION_RELATIONSHIP_WITH_TRANSFORMATION` (simple and complex instance), `ITEM_DEFINED_TRANSFORMATION`, `AXIS2_PLACEMENT_3D`, and gives each occurrence a 4x4 child-to-parent matrix (`StructureOccurrence`). The child and parent frames are decided by matching the relationship's representations to the usage's product definitions (`SHAPE_DEFINITION_REPRESENTATION`), so both orders work; an occurrence that cannot be matched has no placement and is never given an invented one. New: `Structure/StepGeometry.cs`, `Structure/AssemblyLayout.cs` (`AssemblyLayouts.Expand`: world matrices, instance paths, world boxes, bounded).
- **Boxes.** Per part from its own B-rep (vertices, exact circular arcs with their sense, ellipses, B-spline control points); assemblies are the union of their instances. Length unit from `LENGTH_UNIT` (file-wide). Equal to the dimensions of the generating scripts on the real fixtures.
- **Stored and exposed.** Migration 0031: `cad.bom_proposal_occurrence`, `cad.bom_proposal_part.bbox`, `cad.bom_proposal.length_unit(_mm)`; frozen with the proposal by the existing guard trigger; no UPDATE or DELETE grant. API `GET /api/v1/cad/bom-proposals/{number}/placements` and `GET /api/v1/cad/documents/{number}/placements` (OpenAPI regenerated); proposal detail has `occurrences`, `placedOccurrences`, `lengthUnit`, part `box`. CLI `keel-cad bom placements` and `keel-cad placements`.
- **Viewer tab** on document pages (model documents) and part pages (where a `model-of` association exists): `ModelViewerPanel` and `PartModelViewerPanel` (`Components/Pages/Cad`), `AssemblyViewService` (Keel.Cad, reads through `IViewableFileSource`), `ModelViewerPanel.razor.js` (three.js from the vendored viewer bundle; own orbit controls), `css/model-viewer.css`. STEP as placed boxes with the structure list as text alternative, STL/OBJ/3MF as triangles via the existing access-checked mesh route, glTF/GLB/IGES as a link to the full viewer. Keyboard: arrows, Shift+arrows, +/-, 0/Home; the same as named buttons. Themes from tokens; forced colours from the system palette.
- **Registries (union):** `ActivityCatalog.Views` (`cad.bom_proposal.placements`; the tab's reads are `document.view` events with handling `assembly`), `cad-openapi.json`, tab ids on `DocumentPage` and `PartPage`, `App.razor` (one stylesheet link), manual chapters 3, 5 and 11, ADR index, assumptions.

## Tests
- Unit: `CadPlacementTests` (17: real AP203/AP214/AP242 fixtures, boxes against known dimensions, all protocols agree, both representation orders, rotated placement, simple relationship form, missing/foreign/degenerate/dangling placement, arcs in both senses, closed circle, mixed and inch units, hostile loop), `AssemblyViewServiceTests` (9: authorization before any read, gates, size, type, delivered and refused audit, unreadable STEP), `CadPlacementsCliTests` (2). Full unit suite 1402 passed before these were added; see the final report for the count after.
- Integration (`CadPlacementsTests`, 4, real PostgreSQL, vault and host): stored rows and API shape, immutability (app role cannot change; migrator is stopped by the trigger once the proposal is no longer a draft), **SQL oracle**: for four subjects (US person, non-US person, no program, no CUI category) the proposal and document routes agree with the read filter evaluated by the database, no part name in any refusal, denial and delivery audited; document route for STEP, non-STEP (422 `cad.no_placements`) and damaged files, unknown number 404.
- E2E (`ModelViewerTests`, 6, real browser): a real STEP assembly drawn (21 boxes, non-blank canvas), text alternative with 24 nodes, keyboard orbit/zoom/reset and the buttons, selection facts, banners and no console errors under the strict CSP; STL triangles and the part page's tab only where a model is attached; a reader the markings keep out sees nothing; axe clean on the tab in the light, dark and high-contrast themes (STEP and STL, with a selection). Manual screenshots extended (`documents-viewer-assembly`, `documents-viewer-mesh`, `parts-viewer-tab`).

## Decisions and limits (see ADR-0052)
- No second tessellator: STEP surfaces stay with the file viewer's OpenCascade WebAssembly importer (LGPL-2.1, ADR-0027); the tab says boxes are boxes. Release engineering still owes the OCCT source offer for the offline bundle (ADR-0027).
- No new vendored asset and no CSP change; the tab runs under the global policy.
- Mapped-item placements, per-instance transforms for non-STEP structure formats, a root number input on the tab, and stored derived placements for documents are not built.
