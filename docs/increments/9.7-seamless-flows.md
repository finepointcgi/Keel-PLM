# 9.7 Seamless everyday flows (2026-10-31)

No migration, no new permissions. Every change calls the same services as before, so markings, banners, access rules, separation of duties and the audit chain are unchanged. ADR: [0063](../adr/0063-one-review-step-and-one-task-page.md). Commits c10fd73, da4e1b5, d14092d, 558da12, 809bf90.

## What changed

- **One review step in the header.** `ReviewStrip` sits in the header of parts, documents, changes, baselines, specifications, MBOMs, deviations, NCRs, CAPAs, gates, suppliers and process plans. It says where the item is (ready, waiting for whom, rejected, released) and offers the one next button: Submit for review, or Review and sign for the person holding the open task. Progress shows the workflow map inline; Cancel review asks for a reason. The Review tab panels keep the history and the map but no longer start or cancel reviews. Records pages without a header (holds, dispositions, schedules, list entries) keep the buttons inside `SourcingReviewPanel` (`Controls` parameter).
- **Submit dialog lists reviewers on open** (eligible people per slot, roles shown without the `plm-` prefix), so a review starts without typing a search.
- **One task page.** `/tasks/{id}` shows the review summary (revision, submitter's note, content hash) and the decision buttons; `/approve` and `/approve/{id}` redirect to My tasks and the task page. My tasks is a table on desktop and cards on a phone, and also lists change tasks assigned to you, with the banner covering both.
- **Home.** Part search box, create actions above the tiles (adds New baseline), "Review and sign" on attention items that are tasks, phone layout without the intro paragraph.
- **Part and document pages.** Only allowed lifecycle moves are buttons; the reasons others are blocked sit in a quiet "Why can't I move it to another state?" line. Request change (ECN, released parts) and Create baseline are links in the header. After adding a document the Documents tab opens. The link type in Add document is folded away.
- **Forms.** New change explains ECR vs ECN with a switch link that keeps `?part=`; priority, class and reason are under More details (markings stay visible). New baseline folds milestone and configuration under More options.
- **Documents edit like parts.** Edit, Save (with a change note) and Discard changes replace Check out, Check in and Undo check-out; Save draft sits under More. The same `DocumentService` calls run behind them.
- **Layout fixes.** Checkbox rows in forms sit on one line; list cards have row styles; the phone stepper has no connectors.

## Tests

`ReviewStrip`-driven flows are covered in `SimplifyFlowsTests`, `WorkflowAdminMobileTests`, `GapCTests`, `AccessibilityTests` and `WorkflowComponentTests`. The helper `OpenTabAsync` waits for the tabs before opening a group. `KEEL_MANUAL_SCREENSHOTS=1` regenerated all 234 manual images.

## Known gaps

- The part header is tall on a narrow screen (watch-level dropdown inline).
- Dark and high-contrast screenshots were not checked by eye; the second-user signing flow was only tested by E2E.
- The "Unknown change type" flash seen once on first load was not reproduced.
- `ClamdScannerTests` memory test is flaky under load.
