# 9.1 Model versioning for CAD and mesh files (2026-10-29)

ADR-0046. Migration 0028 (schema `mdl`).

  `ThreeMfReader` (ZIP with entry, size and expansion limits; XML with DTD off; components by explicit stack, depth and instance limits; transforms, units to mm, mirrored

  the plain-language summary), `ModelFormats`, `IStepProductCounter`, `SyntheticMesh` (boxes, UV spheres and L brackets generated in code, binary and ASCII STL writers).
- **`Keel.Cad.Structure.StepProductCounter`**: the port implementation over the existing STEP structure reader (registered in `AddKeelCad`).
- **Migration `0028_model_versions.sql`**: `mdl.iteration_metrics`, one immutable row per document iteration (shape constraint: numbers all present or all absent; triggers
  reject update and delete and check that the measured file belongs to the iteration; app role has SELECT and INSERT only). `VaultReferences` classifies its `file_sha256`.
- **`DocumentService` (partial `DocumentService.Models.cs`)**: `UploadNewVersionAsync`, `GetModelVersionsAsync`, `CompareModelVersionsAsync`, `RestoreModelVersionAsync`,
  `ReviseAsync`, `DownloadVersionsAsync`; `MarkedZip.WriteVersionsAsync` (cover sheet, MARKINGS.txt, VERSIONS.txt and each version under its label).
- **Viewer**: `ViewerService.OpenMeshAsync` (same authorization, limits, gates and audit as a file view), routes `/viewer/mesh/documents/{n}/files/{id}` and
  `/viewer/compare/documents/{n}?a=&b=` (`ModelVersionEndpoints`), standalone `ViewerCompare.razor`, `compare.js` (overlay, side by side, swipe), CSS in `viewer.css`, manifest regenerated.
- **API**: `GET /api/v1/documents/{n}/versions`, `GET .../versions/compare?a=&b=`, `POST .../versions` (multipart note, reviseIfReleased, expectedIteration, file),
  `POST .../versions/{id}/restore`, `POST .../revise`, cookie route `/downloads/documents/{n}/versions.zip?ids=`.
- **UI**: Versions tab on model documents (CAD documents and any document whose primary file is STL, OBJ, 3MF, STEP, glTF or IGES), `ModelVersionsPanel`, `UploadVersionDialog`,
  `GeometryFacts`; the Used-by information is repeated on the tab. Works for the model member of a CAD package, which is an ordinary document page.
- **Demo seed**: `DemoSeeder.Models.cs` creates "ORCA gimbal bracket model" (ITAR, ORCA) and "Sensor mounting plate model" (open) with two STL versions each, the second through the
  same one-step upload; `DemoManifest.Models`.

## Assumptions
- MDL-1: a version is a document iteration; the model of an iteration is its primary file. The Versions tab shows for CAD documents and documents with a model primary file.
- MDL-2: reading the measured numbers needs Read on the document; the visual comparison, the viewer and the ZIP need Download as well (viewing is downloading, VWR-2).
- MDL-3: documents are not under change control yet, so "Revise" is a direct action for anyone who may modify the document, only on a Released latest revision, with a required
  reason, audited as `document.revise`. When documents join change control, that gateway replaces it.
- MDL-4: a version whose primary file is quarantined is invisible (list, counts, compare, restore, ZIP); a disposed document shows no history.
- MDL-5: measurement is lazy (at most eight versions per view; the rest show "measuring") and eager for versions created by upload or restore; a vault outage or integrity failure is
  not stored as a result. Identical bytes reuse the stored result.
- MDL-6: the fingerprint snaps to 1/100,000 of the diagonal; it is triangulation dependent and may call a near-identical export "different"; it does not call different shapes the same.
- MDL-7: "watertight" means every edge is shared by exactly two triangles in opposite directions after welding; only then a volume is stored. An inside-out closed mesh reports a
  negative signed volume and a positive volume.
- MDL-8: STL and OBJ are unitless ("units"); 3MF is converted to millimetres; a summary says "mm" only when both sides are millimetres.
- MDL-9: "taller" follows the up axis of the format: Z for STL and 3MF, Y for OBJ; X is width.
- MDL-10: limits: 100 MiB per file, 2,000,000 triangles to measure, 1,000,000 per side to compare visually, OBJ polygons fan-triangulated (correct for convex faces), 3MF production
  extension (parts in other files) and beam lattices not read, STL/OBJ/3MF only for the visual comparison.
- MDL-11: restore copies the files and description of the old version into a new iteration of the LATEST revision, so restoring from an earlier revision works while the latest is editable.
- MDL-12: a caller who sends no expected version stacks behind concurrent uploads in order; with one, only the first of several racing uploads wins.
- MDL-13: no automatic registration; a pair with different up axes is shown as stored and the toolbar says so. No burned-in screenshot in the compare page.
- MDL-14: the history lists the primary file only; attachments are carried by the normal check-in and shown on the Overview tab.
- MDL-15: audit payloads of the new actions carry labels, checksums and change notes only.
